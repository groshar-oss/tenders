# איתור מכרזים · גרושר + צי הנדסה

אפליקציה נפרדת שאוספת מכרזים ממנהל הרכש הממשלתי (mr.gov.il), מדרגת אותם לפי ההתאמה לגרושר ולצי, ומתריעה:
- **וואטסאפ** (CallMeBot, חינמי) על מכרז ששווה (ציון גבוה), דחוף (נסגר בקרוב) ותזכורת לפני הגשה של מכרז במעקב.
- **מייל סיכום יומי** (Gmail של בעל החשבון) עם חדשים לגרושר, חדשים לצי ומה שנסגר השבוע.

## מה יש
- איסוף: מכרזים, מכרזים מרכזיים, פטורים וכוונות התקשרות. מילוי ראשוני של 150 יום אחורה, אחר כך כל שעתיים.
- דירוג Gemini לפי פרופיל החברות (נערך בהגדרות), אזור, תגיות. לומד מסימוני "מעניין"/"לא רלוונטי".
- בדיקת תנאי סף: מוריד את חוברת המכרז ומחזיר תנאי סף מול כל חברה, ערבות, לוחות זמנים, סיכונים ושאלות הבהרה.
- מעקב: מעניין / בהכנה / הוגש / זכינו / לא זכינו, הערות, הוספה ליומן.

## הקמה
1. Supabase: להריץ `supabase/migrations/0001_init.sql`, ואז `alter role tenders_app password '...'`.
2. Vercel: לחבר את הריפו ולהגדיר משתנים לפי `.env.example`.
3. Google Cloud: להוסיף redirect URI `https://<app>/api/auth/callback` ל-OAuth client.
4. תזמון: Vercel Cron כל 30 דקות (vercel.json), עם CRON_SECRET.
5. באפליקציה: כניסה ראשונה = בעל החשבון. בהגדרות: להשלים את פרופיל החברות, לחבר Google לשליחה, להפעיל CallMeBot.

## בדיקות
- `npm test` בדיקות יחידה (פענוח עמודי מנהל הרכש, כללי התראה).
- `node tests/e2e/run.mjs` בדיקה מלאה מול Postgres מקומי ושירותים מדומים.
